## CloudFront 정액 요금제를 적용할 수 있는가

출처: AWS 개발자 가이드 "CloudFront flat-rate pricing plans" (2026-11-05 조회).

- 요금: Free $0, Pro $15/월이며 초과 과금이 없습니다. 한도는 Free 100만 요청·100 GB, Pro 1,000만 요청·50 TB입니다. WAF·DDoS 방어·TLS 인증서·Route 53 DNS·S3 크레딧이 포함되고, WAF가 차단한 요청은 한도에서 빠집니다.
- 이 구성은 제약 안에 들어갑니다. 관리형 cache·origin request policy만 쓰고(Free·Pro에는 사용자 정의 policy가 없음), cache behavior는 2개(Free 한도 5), WAF 규칙은 4개(Free 한도 5), IP 기반 rate limit은 Free에도 있습니다. legacy ForwardedValues·OAI·실시간 로그는 쓰지 않습니다.
- **조건 1: 계정이 AWS Free Tier(무료 플랜) 상태면 가입할 수 없습니다.** 계정을 만들 때 유료 플랜을 고르거나 업그레이드해야 합니다. → 사용자 결정 항목입니다.
- 조건 2: 계정당 Free 플랜은 3개까지입니다.
- 조건 3: Terraform 설정으로는 가입할 수 없어서 apply 뒤 콘솔에서 가입합니다. 정액 요금제를 쓰는 배포에는 WAF web ACL이 반드시 붙어 있어야 합니다(이 코드가 붙임).
- Free 한도(월 100만 요청)를 넘을 정도로 커지면 Pro(+약 2,380엔)로 올립니다.

## 정액 요금제를 못 쓸 때(종량제)

CloudFront 상시 무료 한도(월 1 TB, 1,000만 요청) 안이면 CloudFront는 $0입니다. WAF는 공식 요금 페이지(aws.amazon.com/waf/pricing) 기준으로 web ACL $5 + 규칙·관리 규칙 그룹 4개 × $1 + 요청 100만 건당 $0.60이고, 월 50만 요청이면 약 $9.3입니다.
